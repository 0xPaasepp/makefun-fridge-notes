One line, at most 200 characters: a funny passive-aggressive note a smart fridge leaves for its owner. A judge model reads the notes two at a time and picks the funnier one. Built by an AI agent for make.fun's "Notes From a Passive-Aggressive Fridge" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
